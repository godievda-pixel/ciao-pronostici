# Ciao, Web! v23.3 Round 14 UX/Stability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the five remaining v23.3 mobile regressions while preserving all current data/scoring behavior and TEST-only safety.

**Architecture:** Fix each regression in the runtime that owns it instead of adding a new blanket compatibility layer. Predictions identity and Serie A navigation stay in the prediction runtime, Home gets a first-frame canonical placeholder, Matches clears stale theme state during hub navigation, and Tables replace the old narrow-phone fixed width with a true adaptive layout.

**Tech Stack:** Browser ES modules, Node.js `node:test`, Cloudflare Workers/Static Assets, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-03-v23-3-round14-ux.md`

## Global Constraints
- Target `develop`/TEST only; Production must not be switched.
- Preserve prediction scoring, locks, data contracts, ranking logic, and tournament feeds.
- Use TDD: add failing behavior tests before production-code changes.
- Keep all five tournament destinations and full standings stat line.
