# Ciao, Web! v23.3 Round 14 UX/Stability Spec

## Goal
Eliminate the five user-visible regressions reported after Round 13 without changing Production or prediction scoring rules.

## Approved behavior
1. Matches back navigation must return to the tournament hub atomically, without a stale tournament/theme flash.
2. Predictions must never render the generic word `Участник` while identity is loading; use the real Telegram/server identity when available and a neutral reserved placeholder otherwise.
3. Home must occupy its final v23.3 geometry on the first visible frame; data hydration may replace placeholders inside that geometry, but must not rebuild the page from a legacy intermediate view.
4. Selecting Serie A in Predictions must remain fully interactive. The Round 13 Serie A round-navigation synchronization must not create a self-triggering MutationObserver loop.
5. Tables selectors must fit one mobile row with `Серия А`, `ЛЧ`, `ЛЕ`, `ЛК`, `КИ`. Standings must fit phone width without horizontal scrolling, including widths below 420px.
6. Preserve all current tournament data, prediction locks, ranking logic, score calculation, and TEST-only deployment safety.
7. Production remains untouched; changes target `develop`/TEST only.
8. Remove the stale Round 7 deployment-test expectation for the obsolete 660px table width, which Round 12 intentionally removed.
